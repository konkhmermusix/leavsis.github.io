# Leav Sis — Professional Portfolio Website

**Name:** Leav Sis (លាវ ស៊ីស)  
**Role:** Software Developer | IT Enthusiast | Founder of LS Tech Cambodia  
**Brand:** LS Tech Cambodia  

A premium, production-quality personal portfolio website built with an **Apple-inspired Liquid Glass (Glassmorphism)** aesthetic.

---

## 🚀 Features

* **Apple-Inspired Liquid Glass Design System**: Deep black and navy dark theme alongside a crisp frosted pearl white light theme with dynamic backdrop blur, glossy button highlights, border inner shadows, and mouse-tracking spotlight reflections.
* **Persistent Light / Dark Mode Switcher**: Smooth theme toggle button in navbar that preserves your choice in `localStorage`.
* **Full Responsive Support**: Seamless experience across mobile, tablet, laptop, desktop, and large displays.
* **Interactive Project Showcase**: Dynamic project grid with filterable category tabs and detailed architecture modals with feature checklists.
* **Filterable Skill Cards**: Categorized technology cards (Frontend, Backend, Database, Mobile, Tools) with hover lighting effects.
* **Factual Timeline Experience & Education**: Real, factual presentation of developer experience and academic foundation.
* **LS Tech Cambodia Brand Spotlight**: Dedicated section breaking down the brand identity, hashtag `#LSTechCambodia`, and company mission.
* **Interactive Contact Panel**: Direct email, Telegram, and social copy-to-clipboard buttons with instant toast notification feedback + interactive message submission form.
* **Khmer Typography Support**: Native font rendering for Khmer text (**លាវ ស៊ីស**) using Google Font `Kantumruy Pro`.
* **Zero Heavy Framework Dependencies**: Standard HTML5, TailwindCSS, Vanilla JavaScript, and Lucide icons.

## 🛠️ Technology Stack

- **HTML5**: Semantic markup & ARIA accessibility.
- **TailwindCSS**: Responsive layout & utility styling.
- **Vanilla JavaScript**: Modular interaction engine, state management, modal system, filter logic.
- **Google Fonts**: `Plus Jakarta Sans`, `Outfit`, and `Kantumruy Pro` (Khmer script).
- **Lucide Icons**: SVG icon library.

## 🎨 Liquid Glass Utility Classes

* `.glass-card`: Primary frosted glass card container with subtle hover lift and border lighting.
* `.glass-navbar`: Floating glass header navigation with backdrop blur.
* `.glass-pill`: Rounded pill navigation & status tags.
* `.glass-button-primary`: Apple-style glossy gradient call-to-action button.
* `.glass-button-secondary`: Frosted secondary button with subtle hover glow.
* `.spotlight-card`: Mouse cursor radial light tracking.
